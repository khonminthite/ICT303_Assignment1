# Image Classification with MLP and VGG16: Custom and Pretrained Architectures in PyTorch

This repository contains implementations of multilayer perceptron (MLP) and VGG16 models for image classification tasks. 
The project includes three approaches:

Custom MLP: A fully connected neural network.
Custom VGG16: A custom-built version of the VGG16 convolutional neural network (CNN) architecture.
Pretrained VGG16: The VGG16 model is pre-trained on ImageNet.

The models are implemented in PyTorch. The project also utilizes TensorBoard for training/validation curve visualization and evaluates model performance with confusion matrices and Mean Average Precision (MAP). The repository provides Python code, a Jupyter notebook with training/testing demonstrations, and analysis of the models' performance across different configurations.
